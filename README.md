## 🚀 Featured projects

### 🏦 AcctFin ERP &nbsp; ![Active](https://img.shields.io/badge/●-Active%20Development-1D9E75?style=flat-square)

> A production-grade, multi-module Accounting & HR platform built ground-up for Pakistani enterprises.

AcctFin is not a scaffold — it's a fully wired system with 35+ modules spanning the complete financial and HR lifecycle. Every number runs through Python `Decimal` for precision. Every transaction enforces double-entry (debits = credits). Every action is logged in an immutable audit trail.

**Core modules:**
- **General Ledger** — Chart of accounts, journals, trial balance, comparative financials
- **Payroll Engine** — Dual workflow (Batch: Draft → Reviewed → Approved → Vouchers Created; Salary: Draft → Submitted → Approved → Posted), attendance-ratio SC calculation, project-wise salary allocation
- **HR & Attendance** — 16 attendance status codes, CO credit engine, leave management
- **Fixed Assets** — FBR Schedule III depreciation, GoP fiscal year (1 Jul–30 Jun)
- **RBAC Engine** — `module.action` permission key model, role selector, audit enforcement
- **Financial Reporting** — Comparative P&L, Balance Sheet, indirect Cash Flow, drill-down

**Compliance:** FBR · EOBI · KPRA/WHT · Social Charges (20%, 4 sub-components) · Pakistan 2025-26 salaried income tax slabs

`Next.js App Router` `Django/DRF` `PostgreSQL` `TypeScript` `Prisma` `Python Decimal` `Celery`

### 🕌 ILM — Gamified Islamic Learning Platform

> DataCamp-style active learning for Shia Islamic education, powered by an NLP library engine.

ILM reimagines how students engage with classical Islamic texts. Instead of passive reading, learners work through structured exercises — fill-in-the-blank, multiple choice, translation challenges, and chain-of-narration drills — with adaptive difficulty and gamified progress tracking.

**Library Engine (Phase 1):** ~79,000 indexed TextUnits drawn from:
- **Al-Kafi, Man La Yahduruhu al-Faqih, Tahdhib al-Ahkam, Al-Istibsar** (The Four Books)
- **Nahj al-Balagha** — sermons, letters, aphorisms of Imam Ali (AS)
- **Bihar al-Anwar** — encyclopedic hadith corpus by Allamah Majlisi
- **Tafsir al-Mizan** — Quranic exegesis by Allamah Tabatabai

**Features:** 4 exercise types · Adaptive difficulty · Gamified XP system · Full-text Arabic/Urdu search · Multi-corpus cross-reference

`Next.js 14` `Django/DRF` `FastAPI` `PostgreSQL` `NLP` `Arabic text processing`

### 📊 Fixed Assets Management System (FAMS)

> FBR-compliant fixed asset registry built for Khyber Development Trust, KPK.

A standalone asset management system designed to integrate with existing accounting infrastructure via CSV journal exports. Built with full awareness of Pakistani regulatory requirements — not a generic IFRS template adapted post-hoc.

**Key features:**
- FBR Schedule III depreciation rates by asset class
- GoP fiscal year (1 July – 30 June) as native time axis
- KPRA/WHT tax computation on asset-related transactions
- Depreciation schedule generation with straight-line and reducing-balance methods
- CSV journal export compatible with AFMS general ledger import

`Django/DRF` `Next.js` `PostgreSQL` `Python Decimal` `PKR / FBR compliance`
